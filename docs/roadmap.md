# خارطة تنفيذ مرحلية

| المرحلة | النتيجة المطلوبة | الحالة |
|---|---|---|
| 0 — تحليل وتصميم | المتطلبات، المعمارية، نموذج تهديدات، مخطط البيانات، قرارات موثقة | أُنشئت مسودات أولية وتحتاج مراجعة هندسية/محاسبية |
| 1 — تأسيس المشروع | مشاريع .NET، سطح مكتب، مخطط DB، إعدادات بيئة، CI، فحوص أولية | الهيكل أُنشئ؛ البناء لم يُشغّل لغياب SDK وبيئة DB |
| 2 — النواة المحاسبية | دليل الحسابات، الفترات، قيود مسودة/اعتماد/ترحيل/عكس، الأستاذ وميزان المراجعة | لم تبدأ؛ تحقق المجال الأولي فقط |
| 3 — العمليات | المبيعات والمشتريات والصناديق والبنوك والمخزون والربط المحاسبي | لم تبدأ |
| 4 — SaaS | إدارة الخطط والفوترة والدفع والتجديد والحدود ولوحة المشغل | مخطط بيانات تمهيدي فقط |
| 5 — الامتثال السعودي | VAT وXML والتوقيع/التجزئة وQR وتكامل FATOORA واختبارات sandbox | لم يبدأ أي تكامل |
| 6 — وحدات متقدمة | الأصول والرواتب والمشاريع والتصنيع والتقارير والذكاء الاصطناعي | لم تبدأ |
| 7 — إطلاق تجاري | أمن وأداء واستعادة وتحديثات وتوزيع Windows ودعم إنتاجي | ممنوع قبل إغلاق بوابات الأمان والمحاسبة والامتثال |

## الأولويات العملية التالية

1. تشغيل CI في بيئة تحتوي .NET SDK 10 وNode/Rust؛ تثبيت التبعيات وتوليد ملفات القفل ومراجعة/إصلاح أخطاء البناء الفعلية.
2. تشغيل PostgreSQL محليًا، تطبيق `0001_initial.sql` على قاعدة جديدة، ثم اختبار المخطط ودور التشغيل وسياسات RLS باستخدام مستأجرين.
3. اعتماد موفر OIDC وتوصيل middleware الذي يتحقق من JWT ثم يحل `oidc_subject` إلى مستخدم داخلي وعضوية نشطة وصلاحيات.
4. تنفيذ CRUD محدود لدليل الحسابات والفترات مع API tests قبل أي شاشة لإضافة قيد.
5. تنفيذ خدمة ترحيل ذرية واختبارات محاسبية مستقلة قبل الانتقال للمبيعات والمشتريات.
6. مراجعة مواصفات ZATCA والـ PDPL والمنطقة السحابية والتكلفة مع الجهات والمستشارين المناسبين قبل توصيل بيانات إنتاجية.
