# دمج تقارير REPX القديمة

## الأرشيف الكامل

النسخة الاحتياطية `Reports_Backup.zip` تحتوي على 78 ملفًا بصيغة DevExpress XtraReports `.repx`. يحتوي المستودع حاليًا على 15 قالبًا رُفعت منفردة في المحادثة. يمكن استيراد بقية قوالب الأرشيف محليًا عبر السكربت أدناه.

## استيراد المجموعة الكاملة على Windows

من جذر المستودع في PowerShell:

```powershell
.	oolsImport-DevExpressReports.ps1 -ArchivePath "$env:USERPROFILEDesktopReports_Backup.zip"
```

إذا كان الملف المضغوط داخل مجلد آخر، مرّر المسار الكامل الصحيح إلى `-ArchivePath`. يحفظ السكربت ملفات `.repx` في `apps/BusinessERP.Desktop/Reports/Legacy` ويُنشئ `catalog.json` يتضمن التصنيف وإصدار المخطط وأبعاد الصفحة وعدد العناصر والحقول المكتشفة. لا يحذف السكربت الأرشيف الأصلي، ويستخدم محلل XML يمنع DTD.

## ما أُنجز

- حفظ 15 قالبًا أصليًا داخل المستودع دون إعادة تصميمها.
- إضافة خدمة تقرأ البيانات الوصفية من مخططات XML فقط، من دون تقييم تعبيرات التقرير أو إنشاء مصادر بيانات.
- إضافة تبويب في مساحة التقارير يعرض القوالب والتصنيف وإصدار المخطط والحقول المكتشفة وحالة الدمج.
- إضافة أداة Windows لاستيراد جميع قوالب الأرشيف الكامل، مع اختبار عقد للأصول.

## متطلبات إكمال التشغيل الفعلي

- التحقق من ترخيص وحزم DevExpress XtraReports المتوافقة مع مخططات الإصدارات القديمة.
- تعريف كل مصدر بيانات قديم وربط حقوله بواجهات API آمنة ومحددة بالمستأجر.
- إنشاء معاينة وطباعة وتصدير فعليين باستخدام محرك متوافق، مع اختبارات مرئية لكل قالب.
- استكمال مصادر بيانات المشتريات والمخزون والخزائن وكشوف العملاء والضريبة التي لا تتوفر لها كيانات وخدمات كاملة بعد.
- إجراء مراجعة محاسبية وضريبية وأمنية واختبارات ZATCA المناسبة قبل الإنتاج.

تقارير ميزان المراجعة وقائمة الدخل والميزانية الحالية تقارير أولية مبنية على واجهة API وقيود `POSTED`. تبقى القوالب القديمة مفهرسة ومنفصلة حتى ربط بياناتها وتشغيلها فعليًا؛ لا تظهر الواجهة هذه القوالب على أنها تقارير جاهزة للطباعة.
