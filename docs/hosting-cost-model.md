# نموذج تقدير تكلفة الاستضافة — إصدار تمهيدي

لا توجد قيمة شهرية مسؤولة يمكن تثبيتها قبل اختيار مزود الاستضافة ومنطقة التشغيل وحجم قاعدة البيانات ومعدل استخدام التقارير والنسخ الاحتياطية والتخزين. لذلك يعتمد هذا النموذج على المحركات التالية، ولا يعرض أسعارًا مزعومة أو رقمًا تجاريًا نهائيًا.

## فئات حمل مبدئية للقياس

| الفئة | افتراض تخطيطي يحتاج تحققًا | البنية المبدئية |
|---|---|---|
| Pilot | 10–50 شركة، 1–3 مستخدمين نشطين لكل شركة، اختبار داخلي | API صغيرة مدارة + PostgreSQL صغيرة + نسخة احتياطية يومية + سجلات أساسية |
| Growth | 100–500 شركة مع ذروة استخدام متزامن وتقارير متكررة | API قابلة للتوسع أفقيًا + PostgreSQL متوسطة + مراقبة/تنبيهات + تخزين ملفات خاص |
| Scale | 1,000+ شركة أو حمل تقارير/نقاط بيع مرتفع | API متعددة النسخ + قاعدة بيانات أكبر/خيارات قراءة حسب القياس + طابور خلفي + مراقبة وDR واختبار استعادة |

هذه أعداد تخطيطية وليست ضمان سعة. يجب تثبيت معاملات القياس باختبارات ضغط ممثلة قبل التسعير النهائي.

## بنود تُسعّر لكل مزود ومنطقة

1. خدمة تشغيل API وتوزيع الحمل، عدد النسخ وساعات التشغيل.
2. PostgreSQL: فئة CPU/RAM، التخزين، IOPS، HA، النسخ الاحتياطية، الاحتفاظ، واستعادة الكوارث.
3. تخزين المرفقات والفواتير المصدرة والتقارير، طلبات القراءة/الكتابة والنسخ الاحتياطي.
4. نقل البيانات الخارجي، DNS، WAF، الشهادات والخروج إلى الإنترنت.
5. السجلات والمقاييس والتتبع وفترة الاحتفاظ والتنبيهات.
6. البريد والرسائل والـ SMS عند وجودها، ومزود الدفع ورسوم المعاملة.
7. بيئة الاختبار/التجهيز منفصلة، ووقت الدعم والنسخ والاستعادة.

## طريقة استخراج رقم موثوق

- اختيار المنطقة السحابية بعد مراجعة تعاقدية وتنظيمية لمكان البيانات والنسخ الاحتياطية ونقل البيانات الشخصية.
- تحميل مواصفات افتراضية واضحة لكل فئة إلى حاسبة التسعير الرسمية، حفظ نسخة مؤرخة من التقدير، وتحديد عناصر غير مشمولة.
- إجراء اختبار حمل يقيس API requests/sec وعدد الاتصالات النشطة ومدة الاستعلامات وحجم البيانات لكل شركة وحجم المرفقات شهريًا.
- إضافة هامش احتياط تشغيلي، وتسعير الاستعادة/التعافي، ثم تقسيم التكلفة الثابتة والمتغيرة لكل عميل.
- إعادة التقدير بعد pilot حقيقي بدل اعتماد توقعات غير مقاسة.

**المخرج المطلوب قبل الإطلاق:** ثلاثة تقديرات شهرية/سنوية مؤرخة (Pilot/Growth/Scale) مع اسم المنطقة، أحجام الخدمات، افتراضات الحمل، النسخ الاحتياطية، وميزانية التنبيه. لم يُحدّد مزود أو منطقة بعينها في هذه المرحلة، ولذلك لم أختلق أسعارًا.
