# القيود المعروفة

## قيود تمنع البيع
- تطبيق WPF يحتوي على Ribbon Office-like قابل للطي، وتنقل جانبي وتبويبات مساحة عمل وبحث محمّل واختصارات Ctrl+F/N/S/R، وشاشة مبيعات متصلة بالـ API لإنشاء العملاء والمسودات وحساب VAT وترحيل الأثر الداخلي إلى GL. موفر OIDC غير مهيأ/غير مختبر حيًا؛ وبقية شاشات المحاسبة/المشتريات/المخزون والتقارير ما زالت غير مكتملة.
- المبيعات تشمل العملاء ومسودات داخلية يمكن تصنيفها ضريبيًا وحفظ حسابها ثم ترحيل أثرها إلى GL بقيد متوازن ومربوط بالمصدر. لا توجد فاتورة ضريبية/مبسطة قانونية صادرة أو تكامل ZATCA ولا إشعارات دائنة/مدينة أو تحصيل أو أعمار ديون.
- لا تكامل ZATCA/FATOORA مثبت ولا XML/توقيع/تجزئة/QR ولا قبول sandbox.
- الاشتراكات للقراءة؛ لا onboarding ذاتي أو فرض حصص أو checkout أو webhooks أو تجديد أو لوحة مشغل.
- لا مشتريات/موردين/مخزون أو تقييم تكلفة، ولا قبض وصرف أو تسوية بنك.
- لا عملات متعددة أو أسعار صرف؛ القيود تستخدم عملة الشركة الأساسية.
- التقارير المتاحة عبر API تشمل الأستاذ العام وميزان المراجعة وقائمة دخل وميزانية أولية؛ لم تُربط بعد كلها بشاشات WPF، والتدفقات النقدية والقوائم المالية المعتمدة غير مكتملة.
- لا دليل إنتاجي على نشر/مراقبة/backup وrestore أو توقيع وتحديث تطبيق Windows. زر الطباعة وExcel وPDF معطل عمدًا؛ pagination server-side والتحميل التدريجي وإدارة تبويبات مستندات متعددة لم تُنفذ بعد. البحث الحالي يعمل على السجلات المحمّلة محليًا وليس بحثًا عامًا server-side.
- لا مراجعة محاسبية/ضريبية مستقلة أو اختبار اختراق.

## قيود فنية
- 0001_initial.sql هو bootstrap؛ 0002_sales_invoice_drafts.sql ترحيل إضافي لشريحة المسودات فقط.
- يلزم ضبط Oidc:Authority/ClientId/Scope وتسجيل callback لدى موفر هوية، وضبط Authentication:Authority/Audience على API وتوفير مستخدم/عضوية تطابق claim sub. تدفق end-session لدى الموفر غير منفذ؛ الخروج الحالي محلي.
- فحص البريد في API هو تحقق شكلي وليس إثبات ملكية.
- دقة subtotal الأساسية أربع منازل، بينما حساب VAT يقرّب كل بند إلى منزلتين وفق سياسة أولية في الحاسبة. يلزم اعتماد سياسة التقريب نهائيًا من محاسب وضريبي قبل الإنتاج.
- نجاح CI لا يثبت اعتماد قانوني أو أداء إنتاجيًا أو جاهزية بيع.

**التصنيف: غير جاهز للبيع.** استخدمه للتطوير والاختبار حتى استيفاء RELEASE-CHECKLIST.


## ضريبة القيمة المضافة
- يمكن حفظ تصنيف VAT والإجماليات الداخلية ثم ترحيل قيد GL متوازن. هذا ليس إصدارًا قانونيًا، ولا توجد XML/QR/توقيع أو إرسال ZATCA.
- تصنيفات المعاينة (StandardRated/ZeroRated/Exempt/OutsideScope) تصنيفات داخلية وليست بديلًا عن رموز وقواعد ZATCA الرسمية. يلزم سبب للتصنيفات غير القياسية ومراجعة المعاملة الضريبية لكل توريد.
- سياسة التقريب (منزلتان عشريتان لكل بند) مبدئية للمعاينة فقط؛ لا تعتبر سياسة ضريبية معتمدة لكل حالات الإصدار.
