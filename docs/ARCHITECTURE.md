# معمارية Business ERP

## الوضع الحالي
Modular Monolith من WPF desktop وASP.NET Core REST API وPostgreSQL. هيكل الحل لا يثبت جاهزية SaaS إنتاجية.

- Desktop: WPF/XAML على net10.0-windows؛ يتصل بالخادم ولا يتصل مباشرة بقاعدة البيانات. يحتوي الآن على Ribbon مستوحى من Office قابل للطي، وتنقل جانبي/تبويبات مساحة عمل، وبحث في البيانات المحمّلة، واختصارات Ctrl+F/N/S/R، وشاشة مبيعات RTL متصلة بالـ API.
- API: endpoints للمحاسبة والتقارير الأولية، دليل الحسابات، قراءة الاشتراك، العملاء ومسودات المبيعات، حساب VAT المحفوظ وترحيل قيد المسودة إلى الأستاذ العام.
- WPF: شاشة مبيعات RTL متصلة بالـ API تدعم إنشاء العملاء ومسودات البيع وحساب VAT المحفوظ واختيار حسابات وفترة وترحيل الأثر المحاسبي. القوائم قابلة للفرز وتغيير عرض الأعمدة وتصفية العملاء والمسودات مع افتراضية الصفوف. توجد شاشة/تبويبات للتقارير لكن التقارير ليست موصولة بعد بالعرض، والطباعة والتصدير معطلان عمدًا. تدفق OIDC يستخدم متصفح النظام/callback loopback؛ موفر الهوية الحي وخروج الموفر لم يكتملَا.
- Domain/Application: قواعد القيود وعقود سياق المستأجر.
- Infrastructure: EF Core/Npgsql، التحقق من العضوية، TenantTransactionRunner، سجل التدقيق.
- Database: 0001_initial.sql bootstrap و0002_sales_invoice_drafts.sql ترحيل تزايدي للعملاء والمسودات.

## تدفق طلب الأعمال
1. التحقق من JWT باستخدام Authority/Audience المهيأين.
2. مطابقة claim sub بمستخدم محلي فعال.
3. التحقق من عضوية نشطة في X-Tenant-Id؛ الرأس لا يمنح تفويضًا.
4. التحقق من الدور في endpoint.
5. بدء معاملة، وتعيين app.tenant_id باستخدام set_config(..., true)، ثم تنفيذ البيانات ضمن نفس المعاملة.
6. RLS وقيود المفاتيح المركبة تدافع عن حدود المستأجر والشركة.
7. تسجيل أحداث تدقيق مدعومة داخل المعاملة.

## المحاسبة والمبيعات
- المبالغ تستخدم decimal في C# وnumeric(20,4) داخل قاعدة البيانات.
- القيود المحاسبية المرحلة لا تعدل؛ التصحيح بعكس موثق.
- تشمل المسارات المحاسبية الأستاذ العام وميزان المراجعة وقائمة دخل وميزانية أولية من القيود المرحّلة. تقرير التدفقات النقدية غير منفذ.
- مسودة المبيعات تحفظ لقطة العميل وبنودها، وتصنيف VAT ومبالغ الضريبة الداخلية، وتستخدم قيود DB مؤجلة للتحقق من إجماليات الرأس/البنود. يمكن ترحيل الأثر الداخلي بقيد متوازن مرتبط بمصدر المسودة داخل معاملة واحدة، مع منع التكرار والتعديل بعد الترحيل. لا يوجد إصدار فاتورة نظامية أو XML/QR/توقيع أو ZATCA أو تحصيل.
- العملة المتاحة هي العملة الأساسية للشركة؛ لا توجد عملات متعددة.

## النشر المستهدف غير المنفذ
- API على شبكة خاصة مع TLS وPostgreSQL غير مكشوف للعامة.
- Secret Manager، صلاحيات دنيا، وعمليات migration منفصلة عن startup.
- مراقبة وتنبيهات ونسخ مشفرة واستعادة مجربة.
- تطبيق Windows موقّع ومثبت ومحدّث بأمان.
- أدوات التصدير والطباعة وإدارة علامات تبويب المستندات المتعددة والصفحات/التحميل التدريجي غير مكتملة؛ حاليًا يقتصر البحث على السجلات المحمّلة ويُحد عرض المسودات بـ 500 سجل.
هذه المتطلبات لم تُثبت بعد في المستودع كبيئة إنتاج تعمل.
