# سجل التحقق من بيئة الإنشاء

آخر تحديث: 18 أكتوبر 2026، بعد تحويل الواجهة المكتبية إلى C# وWPF.

## الأدوات المتاحة في بيئة الإنشاء

- Node.js: `v22.16.0` (يُستخدم فقط لاختبارات العقود البنيوية).
- Git: متاح.
- Python: متاح.
- غير متاح: .NET SDK، Windows/WPF runtime، PostgreSQL CLI/server، Docker/Podman.

## تم التحقق منه محليًا

- نجحت فحوص Node البنيوية/التعاقدية: **8/8** من `tests/contracts/*.test.mjs`؛ وتشمل الآن تحققًا بنيويًا من قوالب الأنشطة الستة وطريقة تطبيقها على شركة فارغة.
- تمت كتابة تطبيق WPF في `apps/BusinessERP.Desktop/` باستخدام C# وXAML دون اعتماد على React/TypeScript/Tauri.
- أضيفت جداول مرجعية لقوالب دليل الحسابات في SQL لستة أنشطة، مع API لاستعراضها وتطبيقها على شركة لا تحتوي حسابات، وتسجيل العملية في سجل التدقيق.
- تمت إضافة `BusinessERP.sln` وتهيئة CI لبناء التطبيق المكتبي على Windows.
- اجتازت ملفات XAML وXML وJSON وملفات المشاريع فحص التحليل البنيوي محليًا، وتم التحقق من أسماء عناصر XAML ومعالجات الأحداث في C# ومسارات المشاريع الستة في الحل.

## لم يتم التحقق منه بالتشغيل

- لم يُبنَ مشروع WPF ولا خادم ASP.NET، لأن .NET SDK غير متاح في بيئة الإنشاء.
- لا يمكن تشغيل WPF على البيئة الحالية لأنها ليست Windows.
- لم تُطبّق ترحيلات SQL على PostgreSQL، ولم تُنفذ اختبارات RLS أو النسخ والاستعادة.
- لم يُجر اتصال مع FATOORA/ZATCA أو مزود دفع أو بريد.
- لم تُنشأ حزمة EXE/installer نهائية ولم يُختبر التثبيت على Windows نظيف.

هذا السجل يميز بين إنشاء ملفات المصدر والتحقق البنيوي وبين البناء والتشغيل الفعلي. لم يتم بناء C# أو تشغيل SQL على الخادم في هذه البيئة. هذا السجل يثبت فحوص الملفات فقط ولا يمثل قبولًا للإنتاج.
