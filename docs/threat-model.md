# نموذج التهديدات الأولي (STRIDE مختصر)

| الأصل | التهديد | الضابط المطلوب | حالة التأسيس |
|---|---|---|---|
| بيانات المستأجر | عبور أفقي بين المستأجرين عبر IDOR | تحقق عضوية وصلاحية على الخادم + composite FKs + RLS | سياسات SQL موجودة؛ مسار العضوية/اختبارات DB غير مكتملة |
| الجلسة/الرمز | رمز مزور أو مسروق | OIDC/JWT validation، HTTPS، تدوير الجلسات، MFA للإدارة | إعدادات issuer/audience موضوعة؛ الربط الفعلي يتطلب موفر هوية |
| القيد المنشور | تعديل/ترحيل مكرر | معاملة ذرية، unique idempotency/source، قيود عكسية وتدقيق | قواعد مجال أولية؛ تدفق ترحيل كامل لاحقًا |
| معلومات الدخول | أسرار داخل Git أو عميل سطح المكتب | Secret Manager، ملفات env مثال فقط، مراجعة الأسرار | `.gitignore` و`.env.example` موجودان |
| خدمة API | إساءة استخدام/تخمين كلمات مرور/DoS | Rate limits، WAF مناسب، حدود حجم، حماية مزود الهوية | محدد ثابت النافذة داخل العملية بحد 120 طلبًا/دقيقة لكل subject أو عنوان النظير؛ حماية الحافة والحدود المتعددة النسخ ما زالت مطلوبة |
| سجلات التدقيق | حذف/تحوير أو إفشاء بيانات | دور append-only، صلاحيات ضيقة، إخفاء PII، تخزين محمي | الجدول الأولي فقط |
| ملفات العملاء | رابط عام أو وصول غير مصرح | مخزن خاص، signed URLs قصيرة، فحص ملفات وسياسة احتفاظ | مؤجل |
| التكامل الخارجي | تكرار webhook أو تزويره | توقيع/مصادقة callback، idempotency، retry مع dead-letter | مؤجل |
| النسخ الاحتياطية | تسريب أو عدم قابلية الاستعادة | تشفير، فصل الصلاحيات، retention، اختبارات استعادة | مؤجل |
| الذكاء الاصطناعي | تسريب بيانات/حقن أوامر/تنفيذ غير مصرح | أدوات ضيقة، نفس التفويض، موافقة قبل الأثر المالي، تسجيل المصدر | ليس في النطاق الحالي |

## بوابات تمنع الإطلاق

1. لا تفتح أي endpoint بيانات قبل اكتمال مصادقة الهوية والتحقق من عضوية المستأجر.
2. تُنفذ اختبارات عزل مستأجرين باستخدام PostgreSQL ودور التشغيل الحقيقي.
3. فحص أمني واختبار اختراق وتحديد معدلات الطلبات وإجراءات الحوادث.
4. اختبار استعادة كامل للنسخة الاحتياطية في بيئة منفصلة.
5. اختبار المحاسبة والضرائب والامتثال من مراجع أعمال مستقل.
