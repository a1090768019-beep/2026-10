# مراجعة الأمان — أولية وغير معتمدة للإنتاج

## ضوابط موجودة بالمصدر
- JWT bearer عند إعداد Authority/Audience، مع تدفق دخول WPF يستخدم عميل OIDC عامًا ولا يحوي client secret.
- ربط claim sub بمستخدم محلي غير معطل وعضوية مستأجر نشطة.
- فرض حد القيود الشهرية في مشغل PostgreSQL قبل الإدراج، مع قفل معاملاتي لكل مستأجر/شهر ورد HTTP 409 عند تجاوز الخطة.
- TenantTransactionRunner يضبط سياق RLS محليًا داخل المعاملة.
- سياسات RLS وقيود FK مركبة لحماية بيانات المستأجر والشركة.
- audit_logs محمي كـ append-only بواسطة trigger وحقوق قاعدة البيانات.
- قيود unique وأقفال معاملات لمنع بعض سباقات الترقيم والتكرار.
- محدد معدل تطبيق ثابت النافذة على API: 120 طلبًا لكل 60 ثانية لكل subject موثّق، وبحسب IP النظير لغير الموثّق، مع رد 429 وRetry-After. المحدد داخل ذاكرة العملية فقط.
- CI يشغّل PostgreSQL بدور غير مالك وغير superuser.

## مخاطر مفتوحة
| المخاطرة | الوضع | الإجراء |
|---|---|---|
| تسجيل الدخول في WPF وإدارة الرموز | عميل OIDC عبر متصفح النظام وcallback loopback موجود في المصدر؛ لا يوجد موفر حقيقي مهيأ أو اختبار دخول حي، والخروج محلي فقط | ضبط الموفر والجمهور، واختبار PKCE/التجديد/انتهاء الرمز والخروج لدى الموفر |
| إدارة المستخدمين والأدوار | توجد واجهات OWNER/ADMIN لإسناد مستخدم مهيأ مسبقًا، وتغيير الدور/الحالة مع منع تعطيل آخر OWNER، وحصة المستخدمين النشطين؛ لا يوجد onboarding أو دعوات موثقة أو إدارة ذاتية | مراجعة مصفوفة التفويض كاملة، توسيع اختبارات الوصول السلبي، وربطها بواجهة إدارة وموفر الهوية الحي |
| حدود الطلبات/Rate limiting | محدد تطبيق محلي لكل عملية موجود؛ لا يحل محل حماية متعددة النسخ | تحديد المعدلات عند البوابة/الوكيل وضبط Forwarded Headers لمصادر موثوقة وحدود حجم الطلب |
| الأسرار | لا توجد بيئة إنتاج مثبتة | Secret Manager وتدوير ومسح أسرار |
| إعداد الهوية وقاعدة البيانات في Production | بدء التشغيل يفشل الآن إذا غابت قاعدة البيانات أو Authority عبر HTTPS أو Audience | توفير القيم الصحيحة في Secret Manager واختبار الهوية الحية |
| TLS/CORS/network policy | إعداد إنتاج غير منفذ | حصر origins وTLS وعدم كشف DB |
| اختبار اختراق | لم يُنفذ | مراجعة مستقلة قبل تجربة العملاء |
| سجلات التدقيق | بعض العمليات فقط | تغطية الإدارة وتقليل PII |
| النسخ والاستعادة | لا دليل restore | تجربة استعادة في بيئة منفصلة |
| الدفع وZATCA | غير منفذ | webhooks موقعة/idempotent وإدارة أسرار منفصلة |

## بوابات منع الإنتاج
لا توصل بيانات مالية حقيقية أو تفتح API للإنترنت قبل إكمال الهوية والصلاحيات وTLS وتحديد المعدلات والمسح الأمني واختبار اختراق وتجربة restore. لا ترفع أي مفتاح أو شهادة توقيع أو رمز إلى Git. لا تمنح runtime role ملكية الجداول أو SUPERUSER أو BYPASSRLS.
