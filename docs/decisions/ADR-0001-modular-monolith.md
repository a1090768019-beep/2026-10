# ADR-0001: بدء النظام بـ Modular Monolith

- الحالة: مقبول للتأسيس.
- السياق: النظام متعدد الوحدات، لكن لم تثبت بعد أحمال أو فرق تشغيلية تبرر Microservices.
- القرار: API واحدة ASP.NET Core، وحدود مشاريع Domain/Application/Infrastructure واضحة ووحدات مجال منفصلة. قاعدة PostgreSQL واحدة كبداية، مع tenant isolation صارم.
- النتائج الإيجابية: نشر وتصحيح وتشغيل أبسط، ومعاملات محاسبية ذرية أسهل، وتعقيد أقل من الخدمات المصغرة.
- المخاطر: يحتاج ضبط حدود الوحدات ومنع الاعتماد المتبادل. تُستخرج خدمات منفصلة لاحقًا فقط عند وجود مبرر حمل/ملكية/أمان واضح.
