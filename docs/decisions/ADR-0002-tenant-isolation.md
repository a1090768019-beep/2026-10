# ADR-0002: عزل المستأجر في التطبيق وقاعدة البيانات

- الحالة: مقبول للتأسيس، ويلزم إثباته باختبار تكامل.
- القرار: `tenant_id` على كل كيان أعمال متعدد المستأجرين، علاقات/قيود مركبة، RLS مع `FORCE ROW LEVEL SECURITY`، وسياق مستأجر محلي داخل معاملة.
- مصدر الثقة: هوية مصادق عليها + تحقق عضوية وصلاحية في الخادم. لا تقبل API tenant id من جسم الطلب على أنه مصادق عليه.
- شرط تشغيلي: دور API ليس `SUPERUSER` ولا مالك الجداول ولا `BYPASSRLS`. لا بد من فحص ذلك في بيئة الإنتاج.
