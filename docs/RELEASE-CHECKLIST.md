# قائمة قبول الإصدار

## القرار الحالي: غير جاهز للبيع

### البناء والجودة
- [ ] بناء API وWPF وكل مشاريع الحل من commit مرشح.
- [ ] نجاح اختبارات الوحدات والتكامل دون تخطي اختبارات حرجة.
- [ ] مسح اعتمادات/أسرار، وعدم وجود ثغرات حرجة أو عالية غير مقبولة.
- [ ] سجل CI ونتائج الاختبار مرتبطة بإصدار بعينه.

### الهوية والأمان وSaaS
- [ ] OIDC في WPF باستخدام PKCE وتخزين آمن للرموز.
- [ ] مصفوفة أدوار وصلاحيات لكل endpoint والشركة/الفرع.
- [ ] دعوات وتعطيل أعضاء وإدارة platform operator.
- [ ] TLS، rate limiting، حد حجم الطلب، CORS مضبوط ومراقبة.
- [ ] onboarding وفرض الحصص ولوحة اشتراك مفصولة عن دفاتر العملاء.
- [ ] مزود دفع مع webhooks موقعة/idempotent وتجديد/إلغاء/تسوية.

### المحاسبة والمبيعات والمشتريات
- [ ] رحلة من العميل إلى فاتورة ضريبية نهائية متوافقة وترحيل GL والتحصيل والتقارير. API سندات قبض العملاء مع تخصيصها على الفواتير المرحلة وترحيلها موجود، لكن تكاملها مع واجهات WPF والتسوية البنكية ما زال مطلوبًا.
- [ ] تطابق الأستاذ وميزان المراجعة مع قيود مستقلة.
- [ ] VAT والخصومات والإشعارات الدائنة والمدفوعات الجزئية مغطاة بالاختبارات.
- [ ] استكمال دورة المشتريات بواجهة سندات الصرف، والإشعارات الدائنة، ومطابقة أمر الشراء والاستلام والفاتورة؛ API سندات صرف الموردين مع التخصيص والترحيل موجود، لكن لا واجهة WPF أو تسوية بنكية. المخزون يدعم الأصناف والمستودعات والاستلام/الصرف والتحويل والتسلسل والتقييم التاريخي وربط تكلفة البضاعة المباعة بقيود البيع؛ ما زالت الجردات الفعلية والتسويات والمرتجعات ومراجعة سياسة التكلفة والاختبارات المحاسبية المستقلة مطلوبة.
- [ ] مراجعة محاسب مؤهل لسياسات الاعتراف والتقريب والإقفال.

### الامتثال والتشغيل
- [ ] تحديد ZATCA requirements لكل فئة عميل ومراجعة أحدث المواصفات.
- [ ] XML/QR/hash/signature/FATOORA واختبارات sandbox حيث تنطبق.
- [ ] مراجعة PDPL ومواقع البيانات والاحتفاظ/التصدير والحذف والعقود.
- [ ] نشر staging مع secrets خارج Git وmigrations منفصلة.
- [ ] نسخ احتياطي مشفر وتجربة استعادة ناجحة، monitoring/runbooks/rollback.
- [ ] مثبت Windows على جهاز نظيف وتحديث آمن وتوقيع عند توفر الشهادة.
- [ ] اختبار اختراق ومراجعة أمنية مستقلة وشروط استخدام وخصوصية ودعم.

لا يعلن “جاهز للإطلاق التجاري” إلا عند وجود دليل لكل عنصر منطبق وقبول المخاطر رسميًا.
