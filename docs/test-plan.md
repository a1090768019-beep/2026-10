# خطة الاختبارات وبوابات الإصدار

## اختبارات المجال (C#)

- القيد متوازن بمدين/دائن ومكون من سطرين مؤهلين على الأقل.
- رفض القيد غير المتوازن، والسطر الذي له مدين ودائن معًا، والسطر الصفري، والقيم السالبة والحساب الفارغ.
- عند إضافة حالات الترحيل: رفض الفترة المغلقة، رفض المصدر المكرر، صلاحية الحساب والفترة والشركة والمستأجر، وذرية الترحيل والعكس.

## اختبارات تكامل قاعدة البيانات

تشغّل على PostgreSQL حقيقي وليس على mocks: RLS لمستأجرين اثنين بدور التطبيق، composite FKs، عزل بيانات الشركات والحسابات والقيود، transaction rollback، unique idempotency، وعدم تسرب `app.tenant_id` بين الاتصالات.

## اختبارات حسابية لاحقة

- مبالغ العملات المختلفة والدقة والتقريب دون `double` أو `float`.
- ضريبة القيمة المضافة، الخصومات، المرتجعات والإشعارات الدائنة/المدينة.
- مطابقة الأستاذ وميزان المراجعة والقوائم.
- المطابقة بين حركة المخزون وتكلفة البضاعة المباعة.
- فروق الصرف وإعادة تقييم أرصدة العملات.
- سيناريوهات API/واجهة من البداية إلى النهاية مع مستخدمين وصلاحيات حقيقية.

## الحالة

اختبارات C# أُنشئت لكن لا يمكن تنفيذها هنا لغياب .NET SDK. اختبار Node الحالي هو فحص بنية/عقد فقط ولا يعوّض الاختبار التنفيذي لـ .NET أو PostgreSQL. يجب ألا تُفتح بوابة مرحلة تالية قبل مرور الاختبارات الحرجة في CI وبيئة تكامل.
