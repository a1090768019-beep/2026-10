# وثيقة المتطلبات — الإصدار 0.1

## النطاق الحالي

الهدف في هذه الجولة هو تأسيس المستودع والحدود المعمارية ومخطط البيانات الأولي وآلية فحص القيد المزدوج. لا تدخل العمليات اليومية أو إصدار الفواتير أو الاشتراكات المدفوعة في نطاق الإنجاز الحالي.

## أصحاب المصلحة

- مشغّل المنصة: إدارة خطط SaaS والمستأجرين وحالة الخدمة.
- مالك المستأجر: إدارة شركاته وأعضائه وإعداداته ضمن حدود الباقة.
- مستخدم الشركة: الوصول إلى الوظائف والفروع المصرح بها فقط.
- المراجع المالي: اعتماد المستندات ومراجعة سجلات التدقيق دون تعديل الأثر المرحّل.
- مسؤول الامتثال/الدعم: إدارة إعدادات التكامل ومراجعة نتائجها بصلاحيات مستقلة ومحدودة.

## المتطلبات غير القابلة للتفاوض

1. لا تُقبل أي عملية محاسبية مرحّلة ما لم يتوازن مجموع المدين والدائن بدقة decimal.
2. ترحيل المستند عملية ذرية؛ ويمنع قيد مصدر مكرر عبر مفتاح idempotency وقيد تفرد مناسب.
3. كل بيانات الأعمال مرتبطة بمستأجر وشركة عند الاقتضاء، ويُفرض العزل في التطبيق وقاعدة البيانات.
4. Tenant ID من واجهة العميل ليس مصدر ثقة. يجب التحقق من هوية المستخدم وعضويته وصلاحياته قبل اختيار سياق المستأجر.
5. القيد المرحّل لا يُعدّل صامتًا؛ يكون التصحيح بقيد عكسي أو مستند تصحيحي موثق.
6. لا تُخزّن المبالغ بأعداد floating point ثنائية. يستخدم C# `decimal` وPostgreSQL `numeric` مع سياسة تقريب معلنة لكل عملة وضريبة.
7. لا تُعرض بيانات تجريبية على أنها معلومات محاسبية فعلية.
8. لا يُعلن توافق ZATCA أو اعتماد المنتج إلا بعد التحقق والاختبارات المطلوبة رسميًا.

## معايير قبول تأسيسية

- توجد تعليمات تشغيل نظيفة وواضحة ومتغيرات بيئة دون أسرار.
- يمكن بناء مشاريع .NET في بيئة تتوفر فيها SDK 10 بعد استعادة الحزم.
- اختبارات المجال تتحقق من توازن القيد ومنع القيم السلبية والأسطر غير الصالحة.
- مخطط SQL يفرض العلاقات والقيود الأساسية وسياسات RLS.
- الواجهة تكشف حالة اتصال API الفعلية ولا تختلق مؤشرات مالية.
- CI يشغّل الفحوص المعروفة ويعرض نتائجها.

## خارج النطاق الحالي

الدخول النهائي وإدارة حسابات OIDC، إدارة الصلاحيات الكاملة، واجهات API للمحاسبة، إنشاء الشركة ودليل الحسابات، دورة اعتماد/ترحيل كاملة، المبيعات والمشتريات والمخزون، المدفوعات، بوابة الدفع، البريد، مراقبة الإنتاج، جميع التقارير، ومواءمة الفوترة الإلكترونية الإنتاجية.
